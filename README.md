# next-career
Companion App for the book
Things to know
**Where progress is saved**: in the reader's own browser, on that device only. Nothing is sent to you or anyone else. Clearing browser data or switching device starts fresh.
**Internet needed to load**: the page loads a small open-source library (React) from a public server the first time. After that it works as normal.
**The app copies prompts**; it does not run them. Readers paste the copied prompt into Claude or ChatGPT. This keeps the app free to host, because running Claude from a public page would need a paid key.
**Add to home screen**: on iPhone use Share > Add to Home Screen. On Android Chrome use the menu > Add to Home screen.
